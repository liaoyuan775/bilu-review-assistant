# 笔录审查与补问清单设计

## 目标

本产品只检查笔录是否存在遗漏、回答不清或事实矛盾，不承载补充询问和案件办理。审查结束后，民警在线下完成需要的补问。

## 人工判断

针对待处理的审查提示，提供三个动作：

- **加入补问清单**：标记为 `supplemented`，进入补问 DOCX；不修改笔录、不要求填写回答、不调用模型复审。
- **当前回答足够**：标记为 `resolved`，不进入补问 DOCX。
- **忽略此提示**：标记为 `ignored`，不进入补问 DOCX。

三种动作均表示该提示已由民警作出判断，理由均可选。自动状态 `not_applicable` 继续作为系统审查结果展示，不再提供“确认不适用”操作。

## 归档与产物

归档表示本次审查结束并转为只读，不表示案件办结或线下补问已完成。前置条件仅包括自动审查完成、解析告警已确认、所有待处理提示已有上述任一人工判断。

归档时自动生成两份用户产物：审查报告 PDF 和补问 DOCX。PDF 保留全部审查结果和人工判断；DOCX 仅保留已加入补问清单的项目。结构化 JSON 和哈希归档清单不再作为归档前置条件或用户下载项。
