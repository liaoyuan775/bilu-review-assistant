# “规则不适用”状态文案设计

## 目标

将自动审查状态 `RuleStatus.NOT_APPLICABLE` 的用户可见名称由“不适用”统一改为“规则不适用”，明确表达“不适用的是当前规则”，并与“适用性待人工确认”区分。

## 变更范围

- 当前审查结果页顶部统计、筛选标签和结果状态标签显示“规则不适用”。
- 兼容页面中的自动状态标签同步显示“规则不适用”。
- 审查 PDF、补问 DOCX 等报告中的自动状态标签显示“规则不适用”。
- 快速上手文档使用“规则不适用”解释自动状态。

## 保持不变

- API 和数据库中的状态值继续使用 `not_applicable`。
- 人工按钮继续叫“确认不适用”。
- 人工处置状态继续叫“人工确认不适用”。
- 自动状态的计算、归档门禁和操作流程不变。

## 验证

- 前端文案测试确认自动标签为“规则不适用”，同时人工按钮仍为“确认不适用”。
- 后端报告测试确认 PDF 和 DOCX 状态映射均为“规则不适用”。
- 运行前端测试、后端报告测试和前端生产构建。
