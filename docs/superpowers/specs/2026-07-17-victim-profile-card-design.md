# 被害人信息悬浮卡设计

## 目标

在审查结果页顶部统计带的右侧空白区域增加被害人信息入口，帮助办案人员快速确认当前笔录对象，同时不挤占“三现四流”审查结果区域。

## 信息结构

- 收起状态展示姓名首字头像、姓名、性别、年龄和民族。
- 展开状态展示姓名、性别、年龄、民族、身份证号、工作单位、住址和联系方式。
- 未从笔录提取到的字段显示“未提取”，不得根据常识补写。
- 身份证号和联系方式沿用笔录中的脱敏值，不在前端恢复或推测完整号码。

## 头像

- 头像内容取被害人姓名的第一个有效字符，不使用人物图标或默认照片。
- 样式从有限的政务界面配色和字重组合中选择。
- 选择结果由姓名稳定哈希决定，同一姓名刷新后保持一致，避免真正随机导致界面跳变。

## 交互

- 桌面端支持鼠标悬停和键盘聚焦显示详情。
- 点击可固定或关闭详情，按 Escape 关闭。
- 触屏端使用点击展开，不能把悬停作为唯一入口。
- 详情浮层覆盖在页面上方，不改变统计带高度，不引起工作区跳动。

## 数据边界

- 被害人信息作为 `ReviewTask` 的可选结构化元数据返回。
- 本地提取只识别笔录中有明确标签或固定表达的字段。
- 该信息不增加审查规则，不改变“三现四流”的七项统计。

## 验收

- 演示样例可展示完整被害人详情。
- 姓名首字与样式选择稳定可测试。
- 悬停、聚焦和点击均可显示详情。
- 前后端测试、类型检查和生产构建通过。
